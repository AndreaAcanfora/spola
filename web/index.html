Every await stops the virtual machine and saves its whole state: stack, heap, call frames. Kill the process while it sleeps or waits for you, then restore it: it continues from that exact line. Drag the thread to travel back in time. A downloaded checkpoint resumes in your terminal with spola resume program.state.

  
Effects here: sleep, ask, now, random. The command line adds files, shell commands and Redis-compatible checkpoint storage.
